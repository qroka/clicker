# UI-правила игры (редизайн, эталон — экран «Ежедневное»)

Цель: убрать «шаблонный веб/ИИ» вид и сделать интерфейс, который дружит с пиксель-артом. Принципы в духе Kole Jain: иерархия и глубина важнее рамок, лишнее убираем, а не добавляем.

---

## 1. Главные принципы

1. **Никаких обводок у карточек.** Блоки отделяются сменой фона и отступами, а не `border: 1px`.
2. **Никаких вложенных карточек.** Карточка внутри карточки — запрещено. Внутри блока допускается только «подложка» под иконку.
3. **Один акцент — золото.** Остальные цвета функциональные (см. палитру) и используются только по назначению.
4. **Глубина через слои поверхности**, а не через тени и рамки.
5. **Меньше текста.** Одна строка вместо абзаца. Объяснения механик — по тапу на «?», а не на экране.
6. **Текст выравниваем влево.** По центру — только одиночные крупные элементы (например, герой в карточке героя).
7. **Состояния должны читаться с одного взгляда**: выполнено ≠ недоступно (см. раздел 6).

## 2. Палитра (токены)

Фон тёплый, «тёмное дерево», а не холодный сине-фиолетовый.

```css
:root {
  /* Поверхности: от самой тёмной к самой светлой */
  --bg-0: #0f0c0a;        /* фон экрана за шторкой */
  --bg-inset: #15110e;    /* «утопленные» области: трек серии, плашка бонуса, фон полосы прогресса */
  --bg-1: #1c1612;        /* основная поверхность (шторка, экран) */
  --bg-2: #241d17;        /* строки/плитки на поверхности */
  --bg-3: #2b231c;        /* подложка под иконку, вторичные кнопки (#2a221c) */
  --line: #3d322a;        /* пустые сегменты, хэндл шторки, контур пустого чекбокса */
  --track: #120e0b;       /* фон полосы прогресса */

  /* Текст */
  --text: #f3e9da;        /* основной */
  --text-2: #a89885;      /* вторичный */
  --text-3: #8a7b6b;      /* подсказки */
  --text-4: #6f6153;      /* совсем служебное (номер дня) */

  /* Акцент */
  --gold: #f2b84b;        /* главный акцент: CTA, прогресс, выделение */
  --gold-edge: #a8701a;   /* нижняя грань золотой кнопки */
  --gold-ink: #2a1805;    /* текст на золоте */
  --gold-dim: #8a6a3a;    /* незавершённый прогресс */
  --gold-bg: #3a2a14;     /* фон выделенной плитки (7-й день) */

  /* Функциональные — только по назначению */
  --plus: #8fdc9a;        /* «+50%», «готово», галочки */
  --plus-bg: #274a2d;     /* фон под галочкой */
  --check-muted: #6fbf7c; /* галочки на прошедших днях */
  --essence: #7fd3f0;     /* числа эссенции */
  --alert: #e5484d;       /* только бейджи уведомлений */

  /* Событие дня — единственный «цветной» блок */
  --event-bg: #2a1f33;
  --event-icon-bg: #3a2b47;
  --event-label: #c3a6de;
  --event-text: #cfc0dc;
}
```

**Запрещено:** фиолетовые кнопки (violet-500 и т.п.), градиентные заливки фона, произвольные новые акценты. Новый цвет появляется только если у него есть смысл (новая валюта, новый тип события).

## 3. Типографика

Два шрифта (оба с кириллицей, Google Fonts):

- **Handjet** (400/600/700) — заголовки экранов, числа, валюты, уровни, счётчики, текст на главных кнопках.
- **Onest** (400/500/600/700) — всё остальное: названия, описания, подсказки.

Системный sans (DejaVu/Noto) не используем.

| Роль | Шрифт | Размер | Вес | Прочее |
|---|---|---|---|---|
| Заголовок экрана | Handjet | 30px | 700 | letter-spacing −0.3px |
| Заголовок секции | Onest | 20px | 700 | letter-spacing −0.2px |
| Заголовок блока (событие) | Handjet | 22px | 600 | line-height 24px |
| Название строки | Onest | 15px | 600 | |
| Основной текст | Onest | 14px | 400 | |
| Подсказка | Onest | 13px | 400 | цвет `--text-3` |
| Надпись-лейбл | Onest | 11px | 700 | UPPERCASE, letter-spacing 1.2px |
| Числа в строках | Handjet | 15–17px | 400 | |
| Текст главной кнопки | Handjet | 21px | 700 | |

Иерархия держится на **размере и весе**, а не на рамках. Уровней максимум три: экран → секция → элемент.

---

## 4. Отступы и скругления

- Боковые поля экрана: **20px**.
- Между секциями: **28px**. Между заголовком секции и контентом: **12–14px**. Между строками списка: **8px**.
- Внутренние отступы строки: `12px 14px 12px 12px`.
- Скругления: шторка **24px** (только сверху), крупные блоки и строки **14–16px**, подложки под иконки **10–12px**, мелкие плитки **8–9px**, полосы прогресса **3px**.
- Минимальная зона нажатия: **44×44px**.

## 5. Компоненты

### Шторка (bottom sheet)
- Фон `--bg-1`, скругление 24px сверху.
- Тень: `0 -1px 0 rgba(255,236,205,.08), 0 -24px 48px rgba(0,0,0,.5)`.
- Хэндл: 40×4px, `--line`, скругление 2px.
- Экран под шторкой затемнён (`opacity ~.35`).

### Кнопка закрытия
- 44×44px, фон `--bg-3`, скругление 12px, иконка-крестик 18px, stroke 2.5px, цвет `--text-2`.
- Красный пиксельный крестик не используем: красный зарезервирован за уведомлениями.
- Обязателен `aria-label="Закрыть"`.

### Главная кнопка (CTA) — «физическая»
```css
height: 58px;
border: 0;
border-radius: 14px;
background: var(--gold);
color: var(--gold-ink);
font: 700 21px 'Handjet';
box-shadow:
  inset 0 2px 0 rgba(255,246,214,.55),   /* блик сверху */
  inset 0 -2px 0 rgba(120,70,10,.25),     /* лёгкая тень снизу внутри */
  0 5px 0 var(--gold-edge),               /* «нижняя грань» */
  0 10px 20px rgba(0,0,0,.35);            /* тень на поверхность */
margin-bottom: 5px;                       /* место под грань */
```
- **Нажатие:** кнопка опускается — `transform: translateY(4px)`, нижняя грань уменьшается до `0 1px 0`.
- Текст — глагол + объект: «Забрать сундук гильдии», а не «Забрать: Сундук гильдии».
- Одна золотая кнопка на экран.

### Блок-событие (баннер дня)
- Фон `--event-bg`, скругление 16px, без обводки, только `inset 0 1px 0 rgba(255,255,255,.06)`.
- Слева иконка 60×60 на подложке `--event-icon-bg`.
- Справа три строки: лейбл («СОБЫТИЕ ДНЯ»), название (Handjet 22), эффект в одну строку, где число выделено `--plus`.

### Строка списка (задание, рецепт и т.п.)
- Фон `--bg-2`, скругление 14px, без обводки.
- Слева иконка 36px на подложке 48×48 (`--bg-3`, скругление 10px).
- Центр: название + счётчик справа в одну строку, под ними полоса прогресса.
- Справа — индикатор состояния 32×32 (см. раздел 6).

### Полоса прогресса
- Высота 10px, скругление 3px, фон `--track`, `inset 0 1px 0 rgba(0,0,0,.5)`.
- Заливка: `--gold` (выполнено) или `--gold-dim` (в процессе), блик `inset 0 2px 0 rgba(255,255,255,.28)`.
- Зелёные полосы не используем.

### Серия входа (стрик)
- Прошедшие дни — маленькие плитки (`--bg-2`, 72px высотой) в «утопленном» треке (`--bg-inset`, padding 6px, gap 5px). Внутри номер дня (`--text-4`) и пиксельная галочка. Иконку награды у полученных дней не показываем.
- Текущий/наградной день — плитка крупнее (96px шириной), фон `--gold-bg`, рамка через `inset 0 0 0 2px var(--gold)`, свечение `0 0 24px rgba(242,184,75,.28)`, надпись «День 7» золотом.
- Счётчик серии в заголовке: пиксельный огонёк + «**7** дней подряд», число Handjet золотом.

### Плашка сегментного прогресса (бонус дня)
- Фон `--bg-inset`, сегменты 10×10px без скругления: заполненные `--gold`, пустые `--line`.
- Текст: «**Бонус дня** — ещё одно задание».

## 6. Состояния

| Состояние | Как выглядит |
|---|---|
| **Выполнено** | Полная яркость (не приглушать!). Полоса `--gold` на 100%. Счётчик заменяется на «готово» цветом `--plus`. Справа галочка на `--plus-bg`. |
| **В процессе** | Полоса `--gold-dim`. Счётчик «2 / 3» цветом `--text-2`. Справа пустой квадрат с контуром `inset 0 0 0 2px var(--line)`. |
| **Недоступно / заблокировано** | Только это состояние приглушается: `opacity .4–.5` + иконка замка. |
| **Можно забрать** | Золотая рамка + свечение на объекте и золотая CTA-кнопка. |
| **Получено (прошлое)** | Сворачивается до минимума: плитка с галочкой, без иконки награды. |

Правило: **серый = недоступно**. Никогда не делать выполненное серым.

---

## 7. Иконки и пиксель-арт

- Все пиксельные изображения: `image-rendering: pixelated`.
- Масштаб только целыми кратными от исходного размера спрайта, чтобы пиксели не «плыли».
- Системные иконки (крестик, галочка, огонёк) тоже рисуем пиксельно: SVG с `shape-rendering="crispEdges"` и сеткой по пикселям.
- Эмодзи в интерфейсе не используем.
- У иконки внутри строки всегда есть подложка (`--bg-3`), чтобы все иконки одинаково «сидели» независимо от формы спрайта.

---

## 8. Тексты

- Одна строка вместо абзаца. Было: «Звёзды падают прямо в сумки: +50% к редкой добыче экспедиций». Стало: «**+50%** к редкой добыче в экспедициях».
- Числа эффекта выносим вперёд и красим (`--plus` для бонусов, `--essence` для эссенции).
- Подсказки короткие: «Пропустишь день — серия начнётся заново».
- Лор и шутки (описания героев, цитаты) оставляем — это характер игры. Но выравниваем влево и не прячем в рамки.

---

## 9. Чек-лист перед мержем экрана

- [ ] Нет `border` у карточек и строк
- [ ] Нет вложенных карточек
- [ ] Используются только токены из палитры, нет фиолетовых кнопок
- [ ] Заголовки и числа в Handjet, остальное в Onest
- [ ] Не больше одной золотой CTA на экран, у неё есть нижняя грань и состояние нажатия
- [ ] Выполненное яркое, серым только недоступное
- [ ] Описания не длиннее одной-двух строк, текст выровнен влево
- [ ] Все пиксельные картинки с `image-rendering: pixelated` и целым масштабом
- [ ] Зоны нажатия не меньше 44×44px, у кнопок-иконок есть `aria-label`
