# 🧪 Гильдия Алхимиков

Уютный кликер с прокачкой для iPhone. Ты — ученик алхимика, которому досталась лавка на Перекрёстке Миров. Стучи по котлу, строй мастерскую, собирай гильдию героев-оммажей из разных вселенных, отправляй их в экспедиции, открывай рецепты и свари Философский камень.

Полное описание механик: [docs/GDD.md](docs/GDD.md).

## Как поиграть на iPhone

1. Откройте ссылку на игру в **Safari**. Её дают GitHub Pages, см. ниже.
2. Нажмите **«Поделиться»** → **«На экран Домой»**.
3. Запустите игру с иконки. Она откроется на весь экран без интерфейса браузера и будет работать офлайн.

Прогресс хранится на устройстве. Чтобы перенести его на другое устройство, откройте **Меню → Сохранение**: там есть код для экспорта и импорта.

## Публикация (GitHub Pages)

Workflow `.github/workflows/deploy.yml` собирает и публикует игру при каждом пуше в `main`. Сначала один раз включите публикацию: **Settings → Pages → Source: GitHub Actions**. После этого игра будет доступна по адресу `https://<user>.github.io/<repo>/`.

## Разработка

```bash
npm install
npm run dev        # локальный сервер (с --host: можно открыть с телефона в той же Wi-Fi сети)
npm test           # юнит-тесты движка
npm run sim        # симуляция баланса: как быстро средний игрок проходит главы
npm run build      # сборка в dist/
npm run icons      # пересобрать PNG-иконки приложения из пиксельных спрайтов
npx tsx scripts/sprite-sheet.ts all sheet.png 6   # лист всех спрайтов для просмотра
```

Параметры симуляции: `npm run sim -- --days 21 --sessions 5 --minutes 12 --tps 3`.

## Структура

```
src/core/      движок: типы, состояние, формулы (чистые функции, без DOM)
src/data/      контент: постройки, рецепты, герои, тексты, прогрессия, достижения
src/art/       пиксель-арт: спрайты-сетки на палитре Endesga 32 (портреты, мир, иконки)
src/ui/        интерфейс на Preact: вкладки, шторки, модальные окна, эффекты
scripts/       симуляция баланса, генерация иконок, скриншоты
tests/         тесты движка (vitest)
```

## Путь в App Store

Игра — обычное веб-приложение, поэтому её можно упаковать в нативное iOS-приложение через [Capacitor](https://capacitorjs.com/). Там же можно подключить Taptic Engine (`@capacitor/haptics`), локальные уведомления о вернувшихся экспедициях и Game Center.
